Definición y objetivo

El mapa de actores (también llamado mapa de stakeholders, matriz de poder-interés o grid de Mendelow) es una herramienta visual y analítica que permite identificar, clasificar y priorizar a todas las personas, grupos u organizaciones que pueden afectar o ser afectados por un proyecto, decisión o iniciativa.

Su objetivo principal es guiar la estrategia de engagement: saber a quién involucrar, cuándo, cómo y con qué intensidad para maximizar el apoyo, minimizar la resistencia y asegurar el éxito del proyecto.

Contexto de uso

El mapa de actores se aplica en múltiples áreas:

|  |  |
| --- | --- |
| Área / Industria | Situaciones típicas de uso |
| Gestión de proyectos | Lanzamiento de productos, cambios organizacionales, implementación de sistemas. |
| Políticas públicas | Diseño de programas sociales, reformas regulatorias, consultas ciudadanas. |
| Desarrollo sostenible / ONG | Proyectos comunitarios, iniciativas ambientales, cooperación internacional. |
| Design Thinking / Innovación | Diseño de servicios, ecosistemas de usuarios, co-creación con múltiples partes. |
| Comunicación corporativa | Gestión de crisis, relaciones con inversores, reputación empresarial. |

Componentes y elementos

Un mapa de actores completo incluye:

Lista de stakeholders: todos los actores identificados (internos y externos)

Atributos de cada actor: poder/influencia, interés, actitud (apoyo/oposición), legitimidad, urgencia.

Posicionamiento visual: ubicación en una matriz (ej. eje Y = poder, eje X = interés).

Relaciones entre actores: vínculos, alianzas, conflictos, dependencias.

Estrategia de engagement: acciones específicas por grupo priorizado.

Símbolos, notación y convenciones

Matriz de poder-interés (Mendelow)

Eje Y (vertical): nivel de poder o influencia (bajo → alto).

Eje X (horizontal): nivel de interés o preocupación (bajo → alto).

Cuadrantes:

Alto poder / Alto interés: Key players → gestionar de cerca.

Alto poder / Bajo interés: Keep satisfied → mantener satisfechos.

Bajo poder / Alto interés: Keep informed → mantener informados.

Bajo poder / Bajo interés: Monitor → monitorear con mínimo esfuerzo.

Otras convenciones visuales

Tamaño del nodo: magnitud del impacto o tamaño del grupo.

Color: actitud (verde = apoyo, rojo = oposición, amarillo = neutral).

Líneas: tipo de relación (sólida = fuerte, punteada = débil; flecha = dirección de influencia).

Tipos y variantes

|  |  |  |
| --- | --- | --- |
| Variante | Ejes / Criterios | Cuándo usarla |
| Power-Interest Grid (Mendelow) | Poder vs. Interés | Proyectos estándar; priorización rápida. |
| Power-Influence Grid | Poder formal vs. Influencia informal | Cuando hay actores con influencia no jerárquica (ej. líderes de opinión). |
| Influence-Impact Grid | Influencia vs. Impacto recibido | Proyectos con alto impacto social o ambiental. |
| Stakeholder Cube | 3 dimensiones (ej. poder, interés, actitud) | Análisis más fino cuando hay muchos actores críticos. |
| Salience Model (Mitchell et al.) | Poder, Legitimidad, Urgencia | Situaciones de crisis o alta complejidad ética/política. |
| Network Map | Nodos y enlaces (relaciones) | Cuando las alianzas y conflictos entre actores son clave. |

Procedimiento paso a paso

Paso 1: Definir el alcance y el objetivo

¿Qué proyecto, decisión o cambio se está analizando?

¿Cuál es el criterio de éxito?

Paso 2: Identificar actores

Lluvia de ideas con el equipo.

Revisar documentación (organigrama, contratos, normativas).

Incluir actores obvios y no obvios (ej. comunidades locales, reguladores, competidores).

Paso 3: Recopilar información

Para cada actor, anotar:

Nombre / grupo.

Rol y relación con el proyecto.

Nivel de poder (bajo/medio/alto).

Nivel de interés (bajo/medio/alto).

Actitud (apoyo, neutral, oposición).

Necesidades, expectativas y riesgos.

Paso 4: Posicionar en la matriz

Dibujar ejes (poder e interés).

Colocar cada actor en el cuadrante correspondiente.

Usar colores o tamaños para añadir dimensiones extra (actitud, impacto).

Paso 5: Priorizar y diseñar estrategia

Alto poder / Alto interés: reuniones frecuentes, co-diseño, involucramiento profundo.

Alto poder / Bajo interés: actualizaciones ejecutivas, evitar sorpresas.

Bajo poder / Alto interés: newsletters, sesiones informativas, canales de feedback.

Bajo poder / Bajo interés: monitoreo pasivo (ej. revisar noticias, redes).

Paso 6: Validar y actualizar

Compartir el mapa con el equipo y ajustar.

Revisar periódicamente (los actores cambian de posición).

Paso 4: Posicionamiento

Key players (gestionar de cerca): Decanos, Rectorado, TI.

Mantener informados: Profesores, Estudiantes.

Mantener satisfechos: Sindicato (evitar que escale).

Monitorear: otros actores secundarios.

Paso 5: Estrategia

Decanos: talleres de co-diseño, pilotos en sus facultades.

Profesores: sesiones de capacitación, reducir carga administrativa.

Sindicato: reuniones privadas para garantizar que no habrá despidos.

Interpretación

El mapa revela que, aunque los profesores tienen poder medio, su alta oposición puede frenar el proyecto si no se gestiona. Los decanos son críticos: su apoyo es necesario para legitimar el cambio.

Ventajas, limitaciones y supuestos

Ventajas

Visual y sencillo: fácil de comunicar a equipos no técnicos.

Prioriza esfuerzos: evita gastar tiempo en actores de bajo impacto.

Anticipa riesgos: identifica opositores clave antes de que bloqueen el proyecto.

Limitaciones

Simplifica relaciones complejas: una matriz 2D no captura todas las dinámicas.

Depende de la calidad de la información: si los datos de poder/interés son erróneos, el mapa engaña.

Estático: los actores cambian de posición; requiere actualización constante.

Supuestos clave

El poder y el interés son medibles y comparables entre actores.

Los actores actúan de forma racional según sus intereses.

El equipo tiene acceso a información fiable sobre los stakeholders.

Errores comunes y cómo evitarlos

|  |  |  |
| --- | --- | --- |
| Error | Consecuencia | Cómo evitarlo |
| Olvidar actores no obvios (ej. reguladores, comunidades) | Sorpresas tardías, bloqueos. | Usar checklist de categorías: interno, externo, cadena de valor y sociedad. |
| Confundir poder formal con influencia real | Subestimar a líderes informales. | Preguntar: “¿Quién puede detener esto aunque no tenga título?” |
| No actualizar el mapa | Estrategias desfasadas. | Revisar el mapa en hitos del proyecto, por ejemplo, cada mes o fase. |
| Tratar a todos los actores igual | Desperdicio de recursos. | Seguir la estrategia por cuadrante; no dar el mismo trato a todos. |

Recomendaciones para uso universitario

Empieza con un caso real o simulado de tu carrera (ej. lanzamiento de un producto, política campus).

Trabaja en equipo: la identificación de actores es más rica con múltiples perspectivas.

Usa plantillas (Mural, Miro, Excel) para no perder tiempo en el formato.

Justifica cada posición: en tu informe, explica por qué un actor está en ese cuadrante (evidencia, citas, entrevistas).

Incluye un plan de engagement concreto (qué harás con cada grupo, no solo el mapa).

Reflexiona sobre limitaciones: menciona qué no captura tu mapa y cómo lo mejorarías.

Conclusión

El mapa de actores es una herramienta esencial para cualquier proyecto que involucre personas u organizaciones. Permite pasar de una lista caótica de "interesados" a una estrategia clara de engagement, priorizando esfuerzos donde más importa. Su valor no está en el dibujo, sino en el análisis riguroso, la actualización constante y la acción derivada de él.
